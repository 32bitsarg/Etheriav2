# Assets Necesarios para el Mapa del Mundo Vivo

Para implementar la modernización visual del mapa, necesitaremos los siguientes archivos. Por ahora usaré placeholders o formas geométricas avanzadas, pero para el resultado final "premium" harán falta estos assets:

## 1. Ciudades y Estructuras
- `map_city_lv1.png` a `map_city_lv5.png`: Sprites isométricos de ciudades que evolucionen visualmente según su nivel.
- `map_barbarian_camp.png`: Un campamento con una pequeña animación de fogata (spritesheet).
- `map_tower.png`: Torres de vigilancia para marcar territorios.

## 2. Unidades y Movimiento (Miniaturas)
- `map_unit_army.png`: Un pequeño icono o sprite de un grupo de soldados (ejército) para representar ataques.
- `map_unit_caravan.png`: Una carreta de bueyes o mercader para representar el comercio.
- `map_unit_spy.png`: Una figura encapuchada para misiones de espionaje.

## 3. Efectos Climáticos (Overlays/Shaders)
- `weather_snow_particle.png`: Una partícula simple para el efecto de nieve.
- `weather_snow_overlay.png`: Una textura de ruido blanco para cubrir el mapa en invierno.
- `weather_leaves_particle.png`: Partículas de hojas secas para el otoño.

## 4. Interfaz y Niebla
- `map_fog_texture.png`: Una textura suave (gradiente de negro a transparente) para el sistema de Niebla de Guerra.
- `map_selection_ring.png`: Un aro de luz para resaltar la ciudad seleccionada.

> [!NOTE]
> Puedes cargar estos archivos en `/apps/web/public/assets/world/` cuando los tengas listos.
